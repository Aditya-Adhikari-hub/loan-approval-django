# Loan Approval Prediction System

A Django web application that predicts loan approval using a machine learning
model trained on historical applicant data.

## Setup

1. Create and activate a virtual environment:

   python -m venv .venv
   .venv\Scripts\activate

2. Install dependencies:

   pip install -r requirements.txt

3. Train the model (creates ml/artifacts/loan_pipeline.joblib):

   python -m ml.train

4. Apply database migrations:

   python manage.py migrate

5. Create an admin account:

   python manage.py createsuperuser

6. Run the tests (optional but recommended):

   python manage.py test prediction

7. Start the server:

   python manage.py runserver

8. Visit http://127.0.0.1:8000/

## Project structure

- ml/ — data loading, preprocessing, model training, and the training script
- ml/artifacts/ — the trained model and its metrics (generated by python -m ml.train, not stored in git)
- prediction/ — the Django app: forms, views, the prediction service, and tests
- accounts/ — user signup/login
- loan_approval_model.ipynb — the full ML workflow with explanations and results
- loan.csv — the training dataset

## How the model works

Three models (Logistic Regression, Random Forest, XGBoost) are trained and
compared using 5-fold stratified cross-validation, on a train/test split made
before any preprocessing or resampling. The model with the best
cross-validated macro-F1 score is selected and refit on all data for
deployment. See loan_approval_model.ipynb for the full analysis.
